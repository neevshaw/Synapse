Lesson 2.2: Supervised vs Unsupervised Learning

Machine learning can be classified into different types based on how the system learns from data. Two primary categories are supervised learning and unsupervised learning.

Supervised Learning involves learning from labeled data, where the correct answers are known. The system uses this data to make predictions for new, unseen inputs.

For example, a model predicting house prices can be trained using historical data with features like square footage and number of bedrooms, paired with the actual sale prices. The model learns the relationship between features and prices to predict future sales.

Unsupervised Learning involves working with unlabeled data. The system tries to find patterns, groupings, or structures without predefined outcomes.

A common use case is customer segmentation. A retailer can group customers based on buying behavior without any prior labels. The algorithm identifies natural clusters in the data, helping businesses target different groups more effectively.

Tip: Supervised learning is often used for prediction tasks, while unsupervised learning is great for pattern discovery and insights.

There is also a third type called Reinforcement Learning, which uses rewards and penalties to teach the system optimal behavior, commonly applied in robotics and game AI.
